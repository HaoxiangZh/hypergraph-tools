# hypergraph-tools (Python)

NumPy implementation of the **tensor t-product** for tensors of any order p ≥ 3, plus helpers for
t-product hypergraph signal processing (t-HGSP). It is a port of the MATLAB toolbox in the same
repository, and the test suite checks it against saved MATLAB outputs.

```bash
pip install "git+https://github.com/HaoxiangZh/hypergraph-tools#subdirectory=python"
```

The only dependency is NumPy.

## Quick start

```python
import numpy as np
import hypergraph_tools as ht

rng = np.random.default_rng(0)
A = rng.random((4, 4, 5))
B = rng.random((4, 2, 5))

C = ht.t_product(A, B)                 # 4 x 2 x 5
Ai = ht.t_inverse(A)                   # t_product(A, Ai) == t_eye(4, 5)

S = A + ht.t_transpose(A)              # t-symmetric
V, L = ht.t_eigh(S)                    # real, orthonormal: S = V * L * V^T
assert np.allclose(ht.t_product(V, L, ht.t_transpose(V)), S)

# any order: tube axes are 2..p-1
A4 = rng.random((3, 3, 4, 2))
x4 = rng.random((3, 1, 4, 2))
y4 = ht.t_product(A4, x4)              # 3 x 1 x 4 x 2
```

## API

| Function | Description | MATLAB name |
|---|---|---|
| `t_product(A, B, ...)` | t-product of two or more tensors (FFT) | `t_product_fft` |
| `t_product_bcirc(A, B)` | t-product by definition, `fold(bcirc(A) @ unfold(B))` | `t_product` |
| `t_transpose(A)` | tensor (conjugate) transpose | `ttranspose` |
| `t_eye(n, tube_shape)` | identity tensor | — |
| `t_inverse(A)` | tensor (pseudo-)inverse | `t_inverse` |
| `t_power(A, k)` | tensor power, any real `k` | `t_power` |
| `t_hadamard(A, B)` | element-wise product in the Fourier domain | `t_hadamard` |
| `t_norm(X)` | tensor magnitude `(X^T * X)^(1/2)` | `t_norm` |
| `t_eig(A)` | eigendecomposition `A * V = V * L` | `t_eigendecomposition` |
| `t_eigh(A)` | eigendecomposition of a t-symmetric tensor, real orthonormal `V` | — |
| `t_fft(A)`, `t_ifft(A)` | FFT / inverse FFT along the tube axes | — |
| `bcirc`, `unfold`, `fold` | block-circulant matrix and (un)folding | same |
| `diag_circ(A)` | DFT block-diagonalization of `bcirc(A)` | `diag_circ` |
| `t_sym(A)` | symmetrize along the tube axes | `t_sym` |
| `signal_tensor(x, M)` | tensor signal from a vector | `signal_tensor` |
| `t_tv(A, X)` | total variation `|X - A * X|` | `t_tv` |
| `t_tv_laplacian(L, X)` | quadratic form `X^T * L * X` | `t_tv_laplacian` |
| `random_tensor(shape)` | random tensor with symmetric slices, symmetrized | `random_tensor` |

## Tests

```bash
pip install -e ".[test]"

```

(`tests/data/matlab_reference.mat`, regenerated by `tests/data/generate_matlab_reference.m`).
